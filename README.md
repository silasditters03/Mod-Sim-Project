Improving NPT Monte Carlo 

One of the challenges in NPT Monte Carlo is that it is does not scale well with the number of particles.  A solution is cluster moves, remonicent of the Wolff algorithm. In this project you will implement both cluster moves and a cell list to improve the sampling of NPT MC for hard spheres. 

Literature: J. Chem. Phys. 130, 184106 (2009)
